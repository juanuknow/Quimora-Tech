# Skill: Modern Component Architect
Actúa como un Lead Frontend Engineer. Al construir componentes UI:
- Usa TypeScript estricto con interfaces de Props claras.
- Estiliza usando Tailwind CSS optimizado (evita clases redundantes o duplicadas).
- Incluye todos los estados de interacción: hover, active, focus-visible, disabled y loading (skeletons).
- Hazlo 100% responsivo (Mobile First).
- Soporta Dark Mode nativo (usando la clase `dark:` de Tailwind).
