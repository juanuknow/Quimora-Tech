# Skill: Anti-AI-Slop Frontend Design
Cuando generes interfaces (React, HTML/Tailwind, CSS):
1. Rechaza la estética clisé de IA (gradientes morados/azules genéricos, tarjetas con bordes izquierdos coloreados, tipografía Inter por defecto en todo).
2. Elige una personalidad visual clara antes de codificar (ej. Minimalista editorial, Brutalismo fino, Dashboard de alta densidad o Neumorfismo suave).
3. Espaciado y Ritmo: Usa escalas numéricas estrictas de espaciado ( Tailwind 2, 4, 8, 12, 16).
4. Tipografía: Combina fuentes con intención (Ej. Display serif para títulos + sans-serif para UI limpia).
5. Accesibilidad (WCAG): Contraste adecuado, estados :focus visibles y etiquetas semánticas HTML5.
